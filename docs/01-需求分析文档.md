# 企业级插装阀资料管理平台 - 需求分析文档

## 1. 项目背景
企业需要一个统一、可控、可追溯的平台，管理插装阀产品技术资料（尤其是 PDF 文档），并保证不同角色访问权限隔离。

## 2. 建设目标
1. 构建中文化企业级资料平台。
2. 实现 PDF 资料全生命周期管理：上传、下载、在线预览、删除。
3. 建立管理员与普通用户权限边界。
4. 建立客户管理模块并支持后续扩展。
5. 形成可直接部署到云服务器的交付件。
6. 建立插装阀型号目录导航、分面筛选和型号明细展示能力，支持从选型到询价的页面闭环。

## 3. 用户角色与权限

### 3.1 管理员
- 用户管理（当前默认初始化管理员账号，可扩展后台用户管理）。
- 资料管理：上传、查看、预览、下载、删除。
- 客户管理：新增、编辑、删除、查看。

### 3.2 普通用户
- 资料查看、预览、下载。
- 插装阀目录筛选、型号明细查看、SUN 型号替代查询和快速选型。
- 客户查看。
- 不可执行新增、编辑、删除。

## 4. 功能需求

### 4.1 登录与认证
- 用户通过用户名/密码登录。
- 未登录用户禁止访问业务模块。

### 4.2 资料管理
- 列表展示资料：标题、描述、上传时间等。
- 上传 PDF（管理员）。
- 在线预览 PDF（浏览器 iframe）。
- 下载 PDF（保留原文件名）。
- 删除 PDF（管理员）。

### 4.3 插装阀目录与选型
- 顶部导航包含：插装阀目录、SUN 型号替代、快速选型、联系询价、资料库、工作台。
- 插装阀目录页采用左侧筛选栏 + 右侧结果显示区的结构。
- 筛选维度包括：关键词、功能分类、控制问题、通口数、流量范围、压力等级、插孔型号、结构特征。
- 筛选栏需要支持展开/收起，避免筛选项过多导致页面过长。
- 产品结果需要支持分页浏览，并在翻页时保留当前筛选和排序条件。
- 应用筛选和重置操作需要放置在筛选栏内更容易触达的位置。
- 结果列表展示：液压符号示意、平台型号、说明、SUN 参考型号、流量、压力、插孔和明细入口。
- 型号明细页展示：关键规格、结构特征、典型应用、替代说明、相关型号和询价入口。
- 快速选型页采用问题引导方式，按控制问题、通口数、流量范围和压力等级生成候选型号。
- SUN 型号替代页支持按平台型号、SUN 参考型号和插孔关键词查询。

### 4.4 客户管理
- 客户列表查询。
- 新增客户（管理员）。
- 编辑客户（管理员）。
- 删除客户（管理员）。
- 字段：客户名称、联系人、电话、邮箱、备注。

### 4.5 审计与安全（当前版本基础能力）
- 基于角色的路由级访问控制。
- 密码哈希存储。
- 文件类型限制为 PDF。

## 5. 非功能需求
- **可用性**：界面简洁，中文提示明确。
- **可维护性**：模块化目录结构，文档齐全。
- **可部署性**：支持 Docker 标准化部署。
- **可扩展性**：客户字段、资料标签、全文检索、流程审批可后续扩展。

## 6. 验收标准
1. 管理员可上传 PDF 并可预览/下载/删除。
2. 普通用户可预览/下载但不可上传和删除。
3. 客户模块可完成基础 CRUD（管理员）和只读访问（普通用户）。
4. 可在云端 Linux 服务器通过 Docker 运行。
5. 登录用户可打开插装阀目录，按筛选条件收敛结果，并进入型号明细页。
6. 登录用户可使用 SUN 型号替代页、快速选型页和联系询价页。
