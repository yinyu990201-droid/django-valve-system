# 企业级插装阀资料管理平台 - 重构更新日志

## 2026-04-21 - 前端展示与产品目录重构

### 背景
本次重构目标是把原“资料与客户管理平台”升级为更贴近插装阀产品选型场景的目录型应用。设计参考来自用户提供的线框草图，以及 Sun Hydraulics 插装阀型号目录页的信息组织方式：顶部导航、目录列表、分面筛选、型号明细和型号替代查询。

参考页面：

```text
https://www.sunhydraulics.com/zh/models/cartridges
```

### 信息架构调整
- 将登录后的默认入口从 `/dashboard` 调整为 `/catalog`。
- 顶部导航调整为：插装阀目录、SUN型号替代、快速选型、联系询价、工作台。
- 原 `dashboard` 保留为工作台，不删除原有入口。
- 客户档案、登录、权限、健康检查和 Docker 部署链路全部保留；PDF 资料入口迁移到型号明细页。

### 新增后端模块
- 新增 `app/catalog.py`。
- 定义 `CatalogItem` 静态目录数据结构。
- 提供目录列表、型号查询、筛选、分面选项和标签展示工具。
- 当前目录数据不写入数据库，避免影响既有 SQLite 数据和生产部署。

### 新增路由
- `/catalog`：插装阀目录导航页。
- `/catalog/<model_code>`：型号明细页。
- `/quick-select`：快速选型页。
- `/sun-replacement`：SUN 型号替代页。
- `/contact`：联系询价页。

### 页面与交互
- 目录页采用左侧筛选栏 + 右侧结果表格结构。
- 目录页支持关键词、功能分类、控制问题、通口数、流量范围、压力等级、插孔型号和结构特征筛选。
- 筛选列表改为原生 `details/summary` 展开收起结构，默认展开前两个高频分组和已有选中项分组。
- 筛选栏顶部增加固定操作区，将“应用筛选”和“重置”移动到更容易触达的位置。
- 产品结果区增加服务端分页，默认每页 6 条，分页链接保留当前搜索、筛选和排序条件。
- 结果表格展示液压符号示意、型号、说明、SUN 参考型号、流量、压力、插孔和明细入口。
- 型号明细页展示液压符号、关键规格、替代说明、典型应用、相关型号和询价入口。
- 快速选型页采用问题式表单，按控制问题、通口数、流量范围和压力等级生成候选型号。
- SUN 型号替代页支持通过 SUN 参考型号、平台型号或插孔关键词查询。
- 联系询价页可从型号明细页带入型号、SUN 参考型号、流量、压力和插孔信息。
- PDF 上传、预览、下载和删除整合到型号明细页，管理员在当前型号下上传资料，普通用户在当前型号下预览和下载。
- 取消独立资料库页面界面，旧 `/documents` 和 `/documents/upload` 路由保留为跳转兼容。

### 视觉重构
- 将原偏展示型的渐变视觉改为工业产品目录风格。
- 使用白底、黑色线框、紧凑筛选栏、规格卡片和结果表格。
- 统一导航、按钮、表格、筛选项、提示和错误页样式。
- 为目录与明细页增加 SVG 液压符号示意，用于替代纯文字列表。

### 测试

- 覆盖范围：
  - 健康检查与登录跳转。
  - 目录筛选页。
  - 目录分页与筛选参数保留。
  - 型号明细页。


### 兼容性说明
- 未修改 `User`、`Document`、`Customer` 数据库模型。
- 未修改 `Dockerfile` 和 `docker-compose.prod.yml` 的运行结构。
- 未删除客户档案、PDF 预览/下载/删除能力；PDF 资料从独立资料库迁移为型号明细页附件。
- 新增 `Document.model_code` 字段，并在应用启动时自动为既有 `document` 表补齐该字段。
- 新增目录数据随代码部署，不依赖数据库迁移。
