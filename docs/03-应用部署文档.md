# 企业级插装阀资料管理平台 - 应用部署文档

## 1. 部署目标
将平台部署到云端 Linux 服务器（如阿里云、腾讯云、AWS、Azure 的 Ubuntu/CentOS 实例）。

## 2. 前置条件
- 已安装 Docker。
- 已安装 Docker Compose（或 Docker 自带 compose）。
- 服务器开放端口（示例：8000）。
- 具备 Git 拉取代码能力。
- 如需运行自动化测试，需具备 Python 虚拟环境和项目依赖。

## 3. 部署步骤

### 3.1 拉取代码
```bash
git clone <your-repo-url>
cd valve
```

### 3.2 配置环境变量
```bash
cp .env.example .env
```
编辑 `.env`，重点修改：
- `SECRET_KEY`
- `ADMIN_PASSWORD`
- `SHOW_DEMO_CREDENTIALS=false`

建议试用环境额外关注：
- `SESSION_COOKIE_SECURE`
- `DATABASE_URL`

### 3.3 构建镜像
```bash
docker build -t valve-doc-platform .
```

### 3.4 运行容器
```bash
docker run -d --name valve-doc-platform \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  --env-file .env \
  --restart unless-stopped \
  valve-doc-platform
```

如果希望直接给企业内部同事访问，推荐改用 compose 方式统一管理：

```bash
docker compose -f docker-compose.prod.yml up -d --build
```

默认映射关系：
- 服务器本机 `127.0.0.1:8000` -> 容器 `8000`
- 对外访问建议由 Nginx 反向代理到 `127.0.0.1:8000`，不要直接暴露 compose 绑定地址。

默认健康检查地址：

```text
http://127.0.0.1:8000/healthz
```

### 3.5 访问系统
浏览器打开：`http://<服务器IP>:8000`

如果使用 `docker-compose.prod.yml`，则直接访问：

```text
先通过 Nginx 代理到域名，再对外访问域名地址
```

### 3.6 配置 Nginx 域名反向代理

项目已提供示例文件：

```text
deploy/nginx/yinyu990201.com.conf.example
```

在服务器上可按以下方式启用：

```bash
cp deploy/nginx/yinyu990201.com.conf.example /etc/nginx/sites-available/yinyu990201.com
ln -s /etc/nginx/sites-available/yinyu990201.com /etc/nginx/sites-enabled/yinyu990201.com
nginx -t
systemctl reload nginx
```

### 3.7 申请 HTTPS 证书

以 Ubuntu 为例：

```bash
apt update
apt install -y certbot python3-certbot-nginx
certbot --nginx -d yinyu990201.com -d www.yinyu990201.com
```

证书申请完成后，访问地址为：

```text
https://yinyu990201.com
```

## 4. 运维操作

### 4.1 查看日志
```bash
docker logs -f valve-doc-platform
```

### 4.2 停止与重启
```bash
docker stop valve-doc-platform
docker start valve-doc-platform
```

### 4.3 升级发布
```bash
git pull
docker build -t valve-doc-platform .
docker rm -f valve-doc-platform
docker run -d --name valve-doc-platform \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  --env-file .env \
  --restart unless-stopped \
  valve-doc-platform
```

### 4.4 功能测试
本项目提供基于 `unittest` 和 Flask test client 的功能测试，覆盖登录、目录筛选、型号明细、快速选型、SUN 替代查询、询价预填、资料上传和普通用户权限。

本地测试命令：

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

发布前建议至少执行：

```bash
python -m unittest discover -s tests -p "test_*.py" -v
docker compose -f docker-compose.prod.yml config
```

## 5. 生产建议
- 使用 Nginx 做反向代理并配置 HTTPS。
- 使用 MySQL/PostgreSQL 替代 SQLite。
- 定时备份 `data/` 目录与数据库。
- 建议接入监控告警（Prometheus + Grafana）。
- 若通过 HTTPS 对外提供访问，请把 `.env` 中的 `SESSION_COOKIE_SECURE=true`。
- 若登录页不希望展示默认账号，请把 `.env` 中的 `SHOW_DEMO_CREDENTIALS=false`。
- 目录数据当前位于 `app/catalog.py`，升级发布时随代码一并部署；如果后续迁移为数据库目录，应增加迁移和备份步骤。
